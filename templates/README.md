# Reporting templates

The templates support two common research workflows.

## Trajectory report

[`trajectory-report.md`](trajectory-report.md) is a readable form for papers, appendices, and system documentation.

## Trajectory comparison

[`trajectory-comparison.csv`](trajectory-comparison.csv) places one trajectory on each row for comparative studies or benchmark summaries.

## Trajectory event log

[`trajectory-events.csv`](trajectory-events.csv) provides a lightweight event-level record using the primitives in the Agentic Energy Taxonomy. It can be populated from orchestration logs and summarized into an Agent Trajectory Card.

The event log is an implementation aid for the disclosure workflow. Researchers may retain only the fields available in their platform while preserving the taxonomy names where possible.
